# Traefik Watcher v2

Go-based Traefik configuration watcher that replaces the bash script version.

## Features

- ✅ **Database-driven**: Reads app state from PostgreSQL
- ✅ **Kubernetes-aware**: Enriches with k8s Service information
- ✅ **Backward compatible**: Can run in Docker/Dokku mode
- ✅ **Atomic updates**: Config changes are atomic (write to temp, then rename)
- ✅ **Hash-based**: Only updates when config actually changes
- ✅ **Graceful shutdown**: Handles SIGINT/SIGTERM properly

## Architecture

```
┌─────────────┐
│  PostgreSQL │  app_deployments, app_public_settings
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  Watcher    │  Queries DB every N seconds
│   (Go)      │  Generates Traefik config
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ Kubernetes  │  (Optional) Enriches with Service ClusterIP
│   Cluster   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│dynamic_conf │  Traefik reads this file
│   .yml      │  (File provider with watch)
└─────────────┘
```

## Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `DATABASE_URL` | Yes | - | PostgreSQL connection string |
| `KUBECONFIG` | No | - | Path to kubeconfig (if not in-cluster) |
| `CONFIG_FILE` | No | `/etc/traefik/dynamic_conf.yml` | Output config file |
| `CHECK_INTERVAL` | No | `30` | Check interval in seconds |
| `PLATFORM_ADAPTER` | No | `dokku` | Set to `k3s` for Kubernetes mode |

## Usage

### Docker/Dokku Mode (Backward Compatible)

```bash
export DATABASE_URL="postgres://user:pass@localhost:5432/citizen"
export PLATFORM_ADAPTER="dokku"
./traefik-watcher
```

### Kubernetes Mode

```bash
export DATABASE_URL="postgres://user:pass@postgres:5432/citizen"
export KUBECONFIG="/etc/rancher/k3s/k3s.yaml"
export PLATFORM_ADAPTER="k3s"
./traefik-watcher
```

### In Kubernetes Pod (In-Cluster)

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: traefik-watcher
  namespace: citizen-system
spec:
  containers:
  - name: watcher
    image: ghcr.io/citizen/traefik-watcher:v2
    env:
    - name: DATABASE_URL
      valueFrom:
        secretKeyRef:
          name: db-secret
          key: url
    - name: PLATFORM_ADAPTER
      value: "k3s"
    - name: CHECK_INTERVAL
      value: "30"
    volumeMounts:
    - name: traefik-config
      mountPath: /etc/traefik
  serviceAccountName: traefik-watcher
  volumes:
  - name: traefik-config
    persistentVolumeClaim:
      claimName: traefik-dynamic-pvc
```

## Database Schema

Queries the following tables:

### app_deployments

| Column | Type | Used For |
|--------|------|----------|
| app_name | VARCHAR | App identifier |
| port | INT | App listening port |
| status | VARCHAR | Deployment status (must be 'deployed') |

### app_public_settings

| Column | Type | Used For |
|--------|------|----------|
| app_name | VARCHAR | App identifier |
| custom_domain | VARCHAR | Custom domain for routing |
| ssl_enabled | BOOLEAN | Enable HTTPS + redirect |

## Kubernetes Integration

When `PLATFORM_ADAPTER=k3s`:

1. Queries database for app metadata
2. Looks up corresponding Service in `citizen-app-<name>` namespace
3. Uses Service ClusterIP for load balancer backend
4. Falls back to app name if Service not found

## Differences from v1 (Bash Script)

| Feature | v1 (Bash) | v2 (Go) |
|---------|-----------|---------|
| **Language** | Bash | Go |
| **Dependencies** | docker, jq, psql, md5sum | None (static binary) |
| **Dokku** | Required | Optional |
| **Kubernetes** | Not supported | Native support |
| **Config Hash** | MD5 | SHA256 |
| **Error Handling** | Basic | Comprehensive |
| **Logging** | Echo to stdout | Structured logging |
| **Shutdown** | SIGTERM only | Graceful with context |

## Troubleshooting

### Config Not Updating

```bash
# Check watcher logs
kubectl logs -n citizen-system deployment/traefik-watcher

# Verify database connection
psql $DATABASE_URL -c "SELECT COUNT(*) FROM app_deployments WHERE status='deployed'"

# Check Traefik file provider
kubectl logs -n citizen-system deployment/traefik | grep "Configuration reloaded"
```

### Kubernetes Services Not Found

```bash
# List citizen app namespaces
kubectl get ns -l citizen.dev/type=app

# Check specific service
kubectl get svc -n citizen-app-myapp
```

### Config File Permissions

```bash
# Ensure watcher can write to config file
ls -la /etc/traefik/dynamic_conf.yml

# Check PVC mount
kubectl get pvc traefik-dynamic-pvc -n citizen-system
```

## Migration from v1

1. Deploy v2 watcher alongside v1
2. Monitor logs to ensure both generate identical config
3. Switch ConfigMap/PVC to point to v2
4. Remove v1 container
